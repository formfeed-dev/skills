# Contributing

Thank you for helping. One thing to know first.

**This repository is generated.** Its files are exported from the repository where Formfeed is
made, and every export replaces what is here. A pull request is read here; when it is taken, it is
carried over by hand and comes back with the next release, so it can take a few days to appear.

Something that does not work as the README says: open an issue with your agent, its version, and
what you expected to happen.
